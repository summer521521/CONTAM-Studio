# CONTAM Studio 0.1.0 中文用户手册

## 1. 版本与运行方式

CONTAM Studio是Windows优先、离线优先的CONTAM教学与研究工作台。关于页会显示：

- `CONTAM Studio 0.1.0`
- 当前commit SHA
- `unsigned_build`或开发版标识
- ContamX和SimRead状态
- 当前语言、主题和数据目录

便携版无需安装：解压到用户选择的应用目录后运行`CONTAM-Studio.exe`。项目、配置、结果、日志和运行临时文件不应放在应用目录。

## 2. 首次启动

首次启动向导依次完成语言、数据目录、ContamX探测和SimRead探测。工具选择器只接受本地Windows可执行文件，并使用固定的`--version`探测，不执行用户输入的Shell命令。

工具状态含义：

| 状态 | 含义 |
| --- | --- |
| 未配置 | 尚未选择工具 |
| 路径不存在 | 已保存路径但文件不存在 |
| 无权限访问 | 无法读取文件 |
| 不是合法可执行文件 | 文件不是受支持的Windows可执行文件 |
| 版本不受支持 | 版本不在当前验证范围 |
| 架构不匹配 | 工具架构与应用不匹配 |
| 版本探测失败 | 无法在限定时间取得可信版本 |
| 工具可用 | 探测成功，运行时仍会在隔离目录复核 |

没有配置工具时，仍可打开项目、编辑草稿、查看历史结果；点击运行会显示明确错误，不会伪造成功。

## 3. 项目与草稿

使用“打开项目”选择PRJ副本。原始PRJ只读保留哈希和快照；编辑进入不可变草稿Revision。属性面板会显示对象、单位、来源证据和可编辑状态。保存表示“另存草稿副本”，不是覆盖原始项目。

应用Patch前检查Diff、源文件哈希和旧值。任一检查失败都保留原项目、草稿和上一份可信结果。顶部撤销/重做只作用于Studio草稿历史。

## 4. AI助手

“分析”模式只读回答；“仿真方案”模式只能提出受支持的结构化语义操作。AI不能访问Shell、任意路径、完整PRJ/SIM或未披露附件，也不能直接写盘。

批准窗口会列出目标、假设、操作、风险、影响对象和实际披露证据。只有用户批准后，Rust领域流程才会执行：

```text
Patch → ContamX → SimRead → 结果分析
```

附件默认只保存在本机。未勾选“发送给AI”的附件不会进入AI请求；未验证多模态能力时，图片只提供存在、哈希、尺寸和备注，AI不会看到图片像素。

## 5. 单次运行

确认草稿后点击运行。Studio为每次运行建立独立临时目录，记录项目哈希、Revision、工具版本、架构和结果哈希。运行失败保留草稿和上一份可信结果，不显示成功结果。

## 6. 多参数研究

研究页支持Zone体积、Zone名称和FlowPath multiplier等已验证参数。每个参数独立定义范围、步长或离散值；笛卡尔积会显示预计组合数并受上限约束。Schedule和Species在缺少安全字节Patch证据时会显示“不支持此参数类型”，不会伪装成已运行。

研究样本具有`queued/running/succeeded/failed/cancelled/partial`等状态。单个样本失败不会伪造整批成功，取消会停止后续工作并清理临时目录。

## 7. 结果与报告

结果页支持分页、筛选、排序、Zone/FlowPath/时间点选择、参数关系图和时间序列图。结果始终绑定项目哈希和研究哈希；旧项目结果会标记为过期，不会静默混用。

可导出HTML、PDF、CSV和JSON。导出使用临时文件和独占提交，不覆盖已有文件。报告包含参数、样本状态、结果哈希、工具版本、图表和AI证据引用。

## 8. 诊断与数据保留

设置页可打开数据、日志和缓存目录，或清理Studio缓存。脱敏诊断只含版本、commit、系统架构、工具状态、语言、主题、运行状态和目录类别，不含PRJ/CSV/SIM正文、凭据、Token、Cookie或未授权附件。

卸载默认只移除应用文件，保留用户配置、项目、研究结果和外部工具。若安装器无法安全提供选项，采用该保守策略，不删除用户数据。

## 9. 常见错误

| 现象 | 处理 |
| --- | --- |
| 未配置ContamX | 设置→官方工具→选择并探测ContamX |
| 未配置SimRead | 设置→官方工具→选择并探测SimRead |
| 版本不受支持 | 使用已验证版本，或保留只读/历史结果功能 |
| 数据目录切换被拒绝 | 先完成受控迁移；应用不会静默切换有内容目录 |
| 结果显示过期 | 使用匹配项目和研究哈希重新运行 |
| 导出目标已存在 | 选择新文件名，Studio不覆盖已有报告 |
| 解析不完整 | 以只读模式查看，未知字段不会被猜测或丢弃 |

## 10. unsigned build

未签名构建不是已签名产品。Windows可能显示“Windows已保护你的电脑”或未知发布者提示。确认来源可信后，可在“更多信息”中继续；正式分发前必须完成组织证书签名、干净Windows安装、升级和卸载验收。
