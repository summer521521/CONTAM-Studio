# 产品范围

v0.1的规范性产品范围、主Persona、P0/P1、非目标和用户门禁见[v0.1产品契约](v0.1-product-contract.md)。本文件保留长期产品边界，不把v0.1目标描述为当前已实现能力。

## 当前方向

- Windows 10/11 64位是首要平台。
- 桌面端首选Tauri 2，前端首选React+TypeScript。
- CONTAM领域逻辑、文件处理、运行管理和结果处理优先使用Python。
- 官方ContamX承担数值求解，不重写CONTAM求解算法。
- 简体中文和英文均为正式支持语言。
- 采用Offline First，没有AI时核心功能仍必须可用；联网AI必须由用户主动启用。
- GUI和AI调用同一套语义化领域接口，前端和AI不得直接修改原始PRJ文本。
- 当前不建立复杂微服务或插件体系。

Tauri、React、TypeScript和Python是已批准的首选方向，但具体通信方式、依赖和打包方案仍需后续技术Spike验证。

## 产品不是什么

- 新的CONTAM求解器。
- 简单的ContamW换皮。
- 只有聊天框的AI包装。
- 通用BIM平台。
- 多求解器仿真平台。

## 当前非目标

- 重写ContamX。
- 完整CAD和三维建筑建模。
- BIM导入。
- EnergyPlus、DeST、Fluent、CFD和Modelica集成。
- 其他求解器适配。
- 插件市场和公开插件SDK。
- 云同步、账户系统和多人在线协作。
- 企业权限管理和大型设计院完整工作流。
- macOS和Linux正式发行。
- 复杂风管系统完整图形编辑。
- 完全自主AI Agent。
- 为未来可能需求建立大量抽象层。

## 尚未解决的文件范围

PRJ完整格式、无损解析、无损回写、未知区块保留、编号重排和复杂引用关系均未解决。在这些能力得到证据支持前，不能把“可打开”解释为“可安全编辑并保存”。
