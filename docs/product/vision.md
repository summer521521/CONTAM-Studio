# 产品愿景

## 核心定位

> CONTAM Studio是一个面向教学与科研的现代化、离线优先、中英文双语CONTAM桌面工作台，使人和AI能够通过同一套安全、结构化、可审查的接口使用官方ContamX。

## 服务对象

首批服务建筑环境、暖通、通风和室内空气品质相关专业的学生，使用CONTAM开展教学的教师，以及开展相关科研的研究人员和研究生。

v0.1不同时承诺三类用户的完整工作流。当前冻结的主Persona、核心任务和量化门禁见[v0.1产品契约](v0.1-product-contract.md)：主Persona为使用教师提供案例完成受控实验的学生或研究生，教师是案例提供者和证据审阅者，复杂科研需求作为后续输入。

## 产品价值

- 降低CONTAM教学和科研工作流的理解与操作门槛。
- 将项目建模、运行管理、结果分析和审查组织在一致的桌面工作台中。
- 在没有AI或网络连接时保留完整核心能力。
- 让人和AI都通过受控领域接口工作，使修改可解释、可验证、可撤销、可追溯。
- 正式支持简体中文和英文，减少教学与研究中的术语摩擦。

## 设计原则

- **官方内核**：官方ContamX负责数值求解，Studio不重写求解算法。
- **离线优先**：本地项目和本地求解是默认路径，联网AI由用户主动启用。
- **安全编辑**：原始PRJ默认不覆盖，未知内容不静默丢失。
- **同一语义**：GUI和AI共用领域模型与工具接口。
- **阶段验证**：以可独立验证的纵向切片演进，不为未验证的未来需求预建复杂体系。
