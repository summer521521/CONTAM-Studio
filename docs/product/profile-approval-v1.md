# v1 Profile and Authority Baseline

这是自动化候选的保守基线，不是H-FINAL或U-FINAL接受记录。

- 推荐Profile：Candidate A，单Zone `volume_m3` -> 官方ContamX -> SimRead `zone_air_state` -> A/B compare/report。
- 第二候选：Candidate B，同一对象和结果族，仅作为教程案例；无Notice时不分发。
- 不支持对象和未知语法：显示只读摘要或整体拒绝，绝不推测保存。
- AI权限：默认关闭；Explain/Collaborate可读取经预览确认的派生证据；Prepare只生成候选Patch/ActionBundle；Execute必须使用一次性、15分钟过期的哈希绑定批准；Never in v1禁止Shell、任意文件、动态MCP和自主科学假设。
- 危险能力：状态改变AI、远程附件、迁移和破坏性清理由策略开关控制，未显式启用时fail-closed。
- 最终需要用户决定：具体教学/科研问题、Candidate A/B选择、官方工具再分发和Studio许可证。缺少这些外部证据时保留`pending_final_acceptance`，不阻塞实现。
