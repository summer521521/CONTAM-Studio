# 用户与使用场景

## 学生

建筑环境、暖通、通风和室内空气品质相关专业学生，需要在课程、实验和毕业设计中理解模型对象、完成受控修改、运行案例并解释结果。

典型场景：

- 在中英文界面中查看教师提供的CONTAM项目及关键对象。
- 基于副本调整Zone、路径或调度参数，并在保存前看到检查结果。
- 将一次运行绑定到明确输入快照，比较参数变化前后的结果。

## 教师

使用CONTAM开展教学的教师，需要准备可复现案例、演示建模与求解链路，并帮助学生理解错误和结果。

典型场景：

- 组织双语教学案例和一致的专业术语。
- 分发不会被练习过程覆盖的原始案例。
- 查看学生修改Diff、验证结果和运行证据链。

## 研究人员与研究生

使用CONTAM开展通风、室内空气品质、污染物传播或相关研究的用户，需要稳定处理真实项目、批量场景和可追溯结果。

典型场景：

- 安全打开复杂PRJ，对不支持内容保持只读或原样保留。
- 管理模型快照、求解器版本、运行输入与结果之间的对应关系。
- 让AI解释项目或提出结构化Patch，同时保留人工审批和确定性验证。

## 暂不服务的场景

当前不针对大众消费者、复杂企业平台、大型设计院完整生产工作流、多人在线协作或多求解器统一仿真。
