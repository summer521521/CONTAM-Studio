# CONTAM Studio 0.4.0 已知限制

- 本版本面向 Windows 10/11 x64；未提供 macOS 或 Linux 构建。
- 构建未进行 Authenticode 代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。
- 精确 1280×720、1440×900、125% 与 200% 系统缩放矩阵未执行；真实 GUI 验收覆盖了主要任务路径，但不能替代全部显示环境。
- 本轮未进行真实 Provider 回归请求；自动测试、既有用户验收与凭据边界不能冒充本次发布包的真实 API 调用。
- 模型目录刷新需要用户主动连接对应 Provider；离线时使用最近一次成功缓存，过期缓存会显示状态提示。
- SimRead 对不满足严格结果契约的工程可能返回结果读取错误。界面会保留 ContamX 成功证据并提示重试或选择其他运行清单，不会伪造结果。
- 当前只支持明确建模的 PRJ 语义修改；任意 PRJ 无损编辑、Schedule/Species 全量参数化不在 0.4.0 承诺内。
- AI 仍是只读助手；任何结构化修改都必须经过 Diff、确定性验证和用户确认。
- 项目、草稿、运行记录、研究和报告是本地用户数据；卸载通常不会自动清理应用数据。
- 另一台全新 Windows 的独立人工安装验收若未实际执行，保持 `not_run`，不能由本机构建或隔离测试推断。
