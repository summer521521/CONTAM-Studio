# CONTAM Studio 0.3.0 已知限制

- 本候选包面向 Windows x64；未提供 macOS/Linux 构建。
- Provider 真实请求、真实 API Key、真实 AI 回答和用户 GUI/UAT 不由自动化门禁替代，必须由用户在最终候选包上单独验收。
- 未签名构建不提供 Authenticode 发布者证明；Windows 可能显示未知发布者或 SmartScreen 提示。
- 模型目录刷新需要用户主动连接并允许访问对应 Provider；离线时只能使用上次成功缓存，缓存过期会显示状态提示。
- 真实 ContamX/SimRead 隔离冒烟、干净机安装和安装器实际运行必须以候选包审计证据为准，不能从源代码构建成功推断。
- 项目、草稿、运行记录和研究报告仍然是本地用户数据；卸载通常不会自动清理应用数据。
- AI 仍然是只读助手；任何结构化修改都必须经过 Diff、确定性验证和用户确认，不能直接覆盖原始 PRJ。
