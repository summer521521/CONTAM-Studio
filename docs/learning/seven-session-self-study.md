# 七次入门学习路线

每次 30-60 分钟，使用官方夹具和隔离副本；不要把用户唯一工程作为练习材料。

| 次数 | 阅读与练习 | 预期观察 | 反思 |
| --- | --- | --- | --- |
| 1 | 阅读 00、01；打开官方夹具 | 看到来源哈希、Profile和能力 | 产品为什么先保护来源？ |
| 2 | 阅读 02、03；追踪 Project 打开 | React 到 Rust 的请求边界 | 哪一层拥有路径？ |
| 3 | 阅读 04；运行 domain 测试 | Zone/Path/opaque 分类 | 未知语法如何保持可逆？ |
| 4 | 阅读 05；运行结果测试 | Run、Result、页和统计 | 结果如何绑定输入？ |
| 5 | 阅读 01、05；检查 ReportModel | 比较和报告引用证据 | 为什么不能混合网格？ |
| 6 | 阅读 06；构造 CSV/ZIP/PDF 样本 | 主动内容和资源上限拒绝 | 附件何时成为证据？ |
| 7 | 阅读 06、07；构造 SimulationPlan | 缺失问题、批准和Trace | AI 的能力上限在哪里？ |

完成后应能用中文说明“点击 -> React -> Rust -> Python -> 官方工具 -> 证据”的路径，并能解释稳定身份、原始保护、单位、只读边界和 AI 不可做的事情。
