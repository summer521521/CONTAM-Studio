# 01 产品地图

主要表面是 Project、Draft、Runs、Results、Compare、Report、Attachments、Assistant、Settings、Activity 和 Evidence。

| 表面 | 作用 |
| --- | --- |
| Project | 来源哈希、Profile、健康和能力 |
| Draft | Diff、批准、不可变Revision |
| Runs/Results | 受控运行、可信结果和分页 |
| Attachments | 隔离接收、分类和证据衍生物 |
| Assistant | 只读证据、计划和批准动作 |

产品的核心不是“多按钮”，而是每个按钮都绑定稳定身份、能力和失败边界。
