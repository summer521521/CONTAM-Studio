# v1 性能与韧性基线

本基线只测隔离夹具和 Studio-owned 临时目录，不读取用户项目或真实 AppData。验证重点是边界正确性与稳定性，不以绕过校验换取速度。

| 场景 | 测量 | 候选预算 | 状态 |
| --- | --- | --- | --- |
| 冷启动/首屏 | 进程到安全空态 | 5 s | 自动化待补充 |
| 官方夹具打开 | 复制、哈希、Zone/网络投影 | 3 s | 321项Python回归通过 |
| Patch Diff | 计划、Diff、严格重读 | 2 s | 自动化通过 |
| Result分页 | 512项页、游标验证 | 500 ms | 自动化通过 |
| Attachment上限 | 50 MiB文件、ZIP枚举 | 5 s | 自动化边界通过 |
| 报告生成 | 确定性HTML/JSON | 2 s | 自动化通过 |
| 低配/低磁盘 | 硬配额拒绝新写入 | 明确错误 | 自动化通过 |

真实 Windows 冷启动、GUI 首帧、官方工具运行和干净机器安装属于 `pending_final_acceptance`；不得把本表候选预算写成实机成绩。
