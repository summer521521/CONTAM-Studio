# AGENT-06 安装、配置、升级、卸载与发布准备

## 边界

CONTAM Studio的安装目录只承载应用资源；配置、项目工作区、结果、运行临时文件、日志和缓存使用Tauri提供的用户目录。首启向导通过受控Rust命令保存配置，官方工具探测只接受固定的ContamX/SimRead类型和固定`--version`参数。未配置工具不会阻止只读项目和历史结果功能，也不会伪造运行成功。

## 安全与迁移

配置文件带有schema版本并采用临时文件写入后替换，迁移是幂等的；迁移失败保留原文件。诊断摘要只包含版本、架构、工具状态、运行状态（当前没有可用运行记录时明确为`not_available`）、语言、主题和脱敏目录类别，不包含PRJ、CSV、SIM正文、凭据或未授权附件。清理缓存只作用于Studio拥有的缓存目录。卸载默认只删除应用文件，保留用户配置、项目和结果。

## 打包状态

构建脚本在`F:/Codex_File/artifacts/contam-studio/agent-06/`生成可审计的便携构建目录和清单；安装器配置保留NSIS/MSI目标，但只有在本机具备官方打包工具时才尝试生成。未配置代码签名时状态明确为`unsigned_build`，不会上传或发布。
