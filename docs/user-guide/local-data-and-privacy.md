# 本地数据与隐私

CONTAM Studio 是 Windows 优先、本地优先、联网增强的桌面工作台。项目、草稿、仿真和结果在本机处理；联网只在你主动配置并调用 Provider、刷新官方模型目录、检查更新或获取官方资源时发生。应用不会静默上传项目、PRJ、模拟结果或其他用户文件。

## 数据目录

Windows 默认应用数据目录为：

```text
%LOCALAPPDATA%\io.github.summer521521.contam-studio
```

仅下载安装包或源代码不会创建这个目录。应用第一次运行后通常会创建它；安装版和便携版都可能使用同一位置。设置中的“打开应用数据文件夹”只打开这个本地目录，不会上传或删除其中内容。

目录中的常见类别如下：

| 类别 | 作用 | 类型 |
| --- | --- | --- |
| `EBWebView` | WebView2 缓存和运行数据 | 缓存 |
| `project-drafts` | 项目草稿、Revision 和快照 | 用户数据 |
| `geometry-documents` | 由 CONTAM Studio 创建的毫米建筑几何文档及一代恢复备份 | 用户数据 |
| `geometry-underlays` | 用户为各楼层导入的 PNG、JPEG 或 PDF 建筑底图副本 | 用户数据 |
| `runs` | 仿真运行记录和证据 | 用户数据 |
| `result-extractions` | 结果提取记录 | 用户数据 |
| `study-runs` | 研究任务和样本 | 用户数据 |
| `study-reports` | 研究报告 | 用户数据 |
| `logs` | 应用日志 | 缓存/诊断 |

`geometry-documents` 使用原始 PRJ 的基线 SHA-256 作为不含路径的项目身份键。它不是 PRJ 的相邻 sidecar，也不会修改原始 PRJ；主文档保存失败时保留一代已验证备份，主文件损坏时应用会只读恢复备份并明确提示。`geometry-underlays` 使用同一项目身份分目录保存经隔离检查和完整哈希验证的图纸副本；前端只凭资源 ID 读取，不保存原文件路径。移除画布引用不会立即删除副本，以便撤销和崩溃恢复仍有证据。设置页的统计由 Rust 后端按固定白名单计算文件数量和占用空间，不读取文件正文，也不遍历白名单以外的目录。当前版本只提供统计和打开目录，不提供删除按钮：草稿、几何文档、底图、运行记录和研究报告可能是用户唯一的工程证据，清理策略需要单独的恢复、确认和保留期设计。

导入建筑底图不会自动把图片发送给 AI。图片会出现在附件中心但保持未选中；只有你明确选择允许 AI 使用、确认披露并主动请求几何草案时，既有 Codex 读图链才会使用像素。PDF 页面当前仅在本地绘制为画布底图，不作为图片像素自动发送。

## 凭据与 AI 请求

Provider API Key 存放在 Windows Credential Manager，不写入 Provider Profile JSON、Archive、日志或前端持久化状态。Codex 登录由 Codex App Server 管理；CONTAM Studio 不读取其他 Agent 的本地登录会话。OpenAI、Gemini、Anthropic 及其他 Provider 只有在你主动配置并发起请求时才使用各自的 API。

发送 AI 请求前，界面会展示本次选择的上下文预览。只有用户选择并确认的结构化上下文才会发送；原始 PRJ 正文、绝对路径和完整结果序列不会自动发送。项目编辑、仿真和结果查看不依赖 AI。

## 卸载与清理

卸载应用通常不会自动删除上述用户数据。删除 WebView 缓存、日志等缓存，与删除项目草稿、运行记录、研究任务和报告是两种不同操作。请在确认备份和恢复需求后，使用 Windows 文件管理器或组织规定的备份策略处理用户数据。
